# Neon OS Advanced Roadmap

## Phase 1: Boot and kernel
- BIOS bootloader
- protected mode transition
- text-mode console
- keyboard input loop

## Phase 2: Memory and FS
- memory regions
- heap structure
- filesystem registry
- package metadata model

## Phase 3: Userland and process system
- process table and scheduler skeleton
- app lifecycle and process states
- ELF loader planning
- secure execution context

## Phase 4: Desktop and customization
- desktop widget system
- theme engine
- taskbar and shell integration
- profile configuration

## Phase 5: Store and security
- signature verification
- sandboxing and package audit
- malware heuristics and quarantine
- trusted-only app model

## Phase 6: Production-grade OS work
- paging and virtual memory
- driver stacks and interrupt routing
- real userland environment
- package repository and signed manifest infrastructure
