# Neon OS Visual Assets

- `neon-emblem.svg` — sharp, angular distro-style neon-green shield logo (512×512).
- `neon-emblem-mono.svg` — single-color emblem for monochrome use, print, and small icon treatments.
- `neon-wallpaper.svg` — 1920×1080 dark Linux-distro-inspired desktop wallpaper with circuit geometry and matching shield branding.

The visuals use a near-black base, high-contrast neon green, crisp geometry, and restrained terminal-style details. These are SVG concept assets and scale cleanly. The current bare-metal prototype does not yet include a graphical desktop or wallpaper renderer.
